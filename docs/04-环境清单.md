## 三、逐项命令

### 3.1 VS Build Tools

若刚才那次没跑完，重跑：

```powershell
winget install --id Microsoft.VisualStudio.2022.BuildTools -e `
  --accept-package-agreements --accept-source-agreements `
  --override "--quiet --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

装完验证：

```powershell
& 'C:\Program Files (x86)\Microsoft Visual Studio\Installer\vswhere.exe' -latest -products * -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64 -property installationPath
```

有输出路径就算成功。之后 `cargo check` 要通过。

### 3.2 Android SDK

两条路，选一条：

**A. 装 Android Studio**（省心，约 1 GB + SDK）
官网下载安装包，装完在 SDK Manager 里勾选：
- Android SDK Platform-Tools
- Android SDK Build-Tools
- Android SDK Platform（最新稳定，如 API 35）
- NDK (Side by side)

**B. 只装命令行工具**（干净）
下载 `commandlinetools-win-*.zip`，解压到 `C:\Android\sdk\cmdline-tools\latest`，然后：

```powershell
$env:ANDROID_HOME = 'C:\Android\sdk'
& "$env:ANDROID_HOME\cmdline-tools\latest\bin\sdkmanager.bat" --sdk_root=$env:ANDROID_HOME "platform-tools" "platforms;android-35" "build-tools;35.0.0" "ndk;27.2.12479018"
```

### 3.3 环境变量

装完设成用户级，永久生效：

```powershell
[Environment]::SetEnvironmentVariable('ANDROID_HOME','C:\Android\sdk','User')
[Environment]::SetEnvironmentVariable('ANDROID_SDK_ROOT','C:\Android\sdk','User')
[Environment]::SetEnvironmentVariable('ANDROID_NDK_HOME','C:\Android\sdk\ndk\27.2.12479018','User')
```

（路径按实际改。NDK 版本号以 `sdkmanager --list` 里看到的为准。）

### 3.4 Rust 的 Android 目标

```powershell
rustup target add aarch64-linux-android x86_64-linux-android
```

只出这两个 ABI：真机是 arm64，模拟器是 x86_64。不出 armeabi-v7a 和 x86，体积能砍一半。

### 3.5 cargo-ndk

```powershell
cargo install cargo-ndk
```

## 四、两个要注意的地方

### 4.1 JDK 25 可能太新

Godot 的 Android 导出和 Android Gradle Plugin 对 JDK 版本有上限。JDK 25 大概率会报兼容性错误。

建议另装一个 **JDK 17**，用 `JAVA_HOME` 指过去，把 JDK 25 留给别的项目。Godot 官方文档长期推荐 17。

### 4.2 Godot 的导出模板单独下

Godot 本体只有一百多 MB，但 Android 导出模板还有约 1.2 GB，在编辑器里 `Editor > Manage Export Templates` 下载。这个第一次导出时才会用到，不着急。

## 五、装完之后的验收

```powershell
cargo check --workspace --all-targets
cargo test -p omrc-transport-lan
cargo ndk -t arm64-v8a -o . build -p omrc-transport-lan
```

三条都过，环境就算齐了。第三条会产出 `libomrc_transport_lan.so`。
